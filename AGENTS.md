# TDI Agent Bootstrap Contract

Before autonomous coding, preregistration/evaluator work, scientific interpretation, attention/ITD/FLAT integration, PR creation, or merge decisions, read:

```bash
git fetch origin agent/ecosystem-roadmap && \
git show origin/agent/ecosystem-roadmap:.agent/TDI_ECOSYSTEM_ROADMAP.yaml
```

If the roadmap cannot be fetched or read, fail closed for major scientific-promotion, holdout, preregistration, cross-repository, or merge decisions. Read-only diagnosis is allowed.

## Confirmatory-run prohibition for autonomous agents

Autonomous agents must never supply a TDI confirmatory `--full` token and must never initiate TDI-7.2 or an equivalent future confirmatory holdout. They may build, test, inspect guards, verify frozen hash chains, and run bounded non-holdout preflight paths.

Roadmap availability is not authorization to run a confirmatory experiment. Such execution requires an explicit human instruction at execution time after the prerequisite evaluator is complete, reviewed, and CI-green.

## Scientific boundary

Frozen TDI-1 through TDI-6.x results remain scoped to their original finite-state experiments. They are not Transformer/attention results. TDI-7.x is the distinct attention/memory research programme and must preserve preregistration, untouched holdouts, competent controls, negative results, and calibration limitations.

FLAT-ATTENTION is an execution target, ITD Simulator is a comparative scientific harness, and SciRust is a promotion target for general reusable primitives. TDI remains the source of truth for its frozen experimental lineage.

Required CI must be green on the exact PR head before merge.

Reread the roadmap at every session start, before preregistration/evaluator/holdout changes, before cross-repository scientific work, after scientific-strategy changes, and before relevant PR/merge decisions.

Do not merge the roadmap itself into `main` unless the user explicitly requests it.
