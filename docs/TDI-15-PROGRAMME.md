# TDI-15.x — Attention/Associative-Memory Phase Transition

Status: **active Stage 0 bootstrap; not frozen; no confirmatory execution authorised**.

## Conjecture

Under matched compute and dynamic-memory budgets, there exists a task-dependent effective memory dimension at which bounded recurrent/associative systems transition from matching a competent full-history reference to suffering a sharp retrieval or prediction deficit.

## Primary null

Performance degrades smoothly with capacity and no reproducible transition-like regime exists after accounting for optimization quality and model capacity.

## Stage map

- **TDI-15.0** — freeze task families, budget accounting, capacity parameterization and transition diagnostics.
- **TDI-15.1** — reuse TDI-8 A0/A1/A2 reference systems without protected final material.
- **TDI-15.2** — dense capacity sweep on development populations.
- **TDI-15.3** — change-point/critical-region analysis with preregistered robustness checks.
- **TDI-15.4** — independent task-family replication if a transition candidate survives.

## Required controls

Equal parameter/compute envelopes, optimization-strength controls, recurrent-only and full-history references, shuffled dependency horizons, smooth synthetic baselines and multiple transition estimators.

## Decision principle

A transition claim requires a reproducible localized change in the slope or failure probability of the frozen endpoint that survives estimator and task perturbations. A merely monotone degradation does not count.

## Ecosystem boundary

TDI-8 owns the reference architectures. FLAT-ATTENTION may later provide an optimized attention implementation, but implementation speed is not evidence for the scientific conjecture.

## Non-claims

TDI-15 does not claim that ASSR replaces Transformers, that one universal critical dimension exists, or that a finite benchmark transition implies an asymptotic phase transition.
