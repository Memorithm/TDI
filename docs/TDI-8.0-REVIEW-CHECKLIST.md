# TDI-8.0 preregistration review checklist

- [ ] TDI-8 is explicitly distinct from TDI-7 and earlier frozen evidence.
- [ ] ASSR and ASSR-H are working labels, not novelty claims.
- [ ] A0/A1/A2/A3 semantics are described without performance claims.
- [ ] Primary contrasts are A2 vs A1 and A3 vs A2.
- [ ] A1/A2/A3 share one total dynamic-memory budget in the primary comparison.
- [ ] Memory accounting includes representation metadata.
- [ ] Task families are frozen before evaluator implementation.
- [ ] Intervention/recovery measurements are leakage-safe.
- [ ] TDI-8.1 must freeze concrete horizons, budgets, seeds and sample counts before TDI-8.2.
- [ ] Final-holdout execution remains human-only.
- [ ] TDI-7.2 holdout surfaces are isolated and untouched.
- [ ] Forge, SciRust, NNIS, FLAT-ATTENTION and SLHAv2 ownership boundaries are explicit.
- [ ] Negative/equivalent/harmful/inconclusive outcomes remain valid.
- [ ] No O(N), constant-memory, tokenizer-free, cognitive-transparency or GPU-speed claim is implied.
